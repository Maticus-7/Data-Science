REJILLA DE LECTURA DEL P-VALOR
La misma regla se aplica a las 4 pruebas

Definición operativa: el p-valor es la probabilidad de observar datos tan extremos como los nuestros asumiendo que H₀ es verdadera. Cuanto más chico, más raros son los datos bajo H₀, más confianza en rechazarla.

α = 0.05
p < 0.05
rechazar H₀
0.05 ≤ p < 0.10
al borde
p ≥ 0.10
compatible con H₀
0.00 0.05 0.10 1.00

Cuidado pedagógico: el p-valor NO es la probabilidad de que H₀ sea verdadera, NO es la probabilidad de que el efecto sea por azar, y NO mide la magnitud del efecto. Es probabilidad condicional de tus datos bajo H₀.

CASO 01 · IC PARA PROPORCIÓN · ESTIMACIÓN HONESTA

¿Cuál es el verdadero default rate del portfolio?

Marta tiene una estimación puntual de 2.8% sobre 5.000 créditos auditados. El directorio le va a preguntar "¿es confiable?". Aquí no hay p-valor, hay rango: el IC95% responde la misma pregunta de manera equivalente: si el valor histórico cae adentro, no hay alarma.

LA PRUEBA
IC para proporción · método Wald

El IC es equivalente a una prueba bilateral: si el valor de referencia cae fuera del IC, rechazás H₀. No hay p-valor explícito porque el rango es la respuesta.

IC1−α = p̂ ± zα/2 · √(p̂(1−p̂) / n)

Para 95%: z = 1.96. Condición de validez: n·p̂ ≥ 10 y n·(1−p̂) ≥ 10 (acá ambas se cumplen).

EL CÓDIGO QUE VAMOS A CORRER
Tres líneas con statsmodels
from statsmodels.stats.proportion import proportion_confint

# IC95% Wald · método clásico cuando n·p̂ y n·(1-p̂) > 10
ic_inf, ic_sup = proportion_confint(
    count=140, nobs=5000,
    alpha=0.05, method="normal",
)
print(f"IC95%: [{ic_inf:.4f}, {ic_sup:.4f}]")
# → IC95%: [0.0234, 0.0326]
PARA LLEVAR AL DIRECTORIO
Un número solo es opinión. Un rango con confianza es información. El IC95% incluye el histórico 2.5%, por lo tanto no hay evidencia estadística para afirmar que el default haya cambiado. Para confirmar esa conclusión con una prueba formal, ver el Caso 02.

Lectura: Hay 17.6% de probabilidad de ver una diferencia así de grande aun si Q1 y Q4 fueran idénticos. Como 17.6% > 5%, los datos son compatibles con H₀. No rechazamos · no aceptamos.

EL CÓDIGO QUE VAMOS A CORRER
Test z con statsmodels + análisis de poder
import numpy as np
from statsmodels.stats.proportion import proportions_ztest
from statsmodels.stats.power import NormalIndPower

# Test z unilateral cola derecha · "Q1 mayor que Q4"
z_stat, p_valor = proportions_ztest(
    count=np.array([140, 120]),       # Q1, Q4
    nobs =np.array([5000, 4800]),
    alternative="larger",
)
print(f"z = {z_stat:.3f}, p = {p_valor:.4f}")
# → z = 0.928, p = 0.1768
EL PROBLEMA DEL PODER
Que p ≥ α NO significa "H₀ es verdadera". Significa "no podemos rechazarla". Quizás el deterioro es real, pero con n=5.000 no tenemos poder estadístico para detectarlo. La notebook computa que para detectar Δ=0.5pp con poder 80% hacen falta ~15.000 créditos por brazo. Ausencia de evidencia ≠ evidencia de ausencia.

RECHAZAR H₀

Hay diferencias. ANOVA no dice cuáles: para eso corremos Tukey HSD, que compara TODOS los pares ajustando el p-valor. Esperá ver que Trujillo > Lima con p ajustado significativo.

POR QUÉ NO HACER 6 t-TESTS
El problema de las comparaciones múltiples

Con 4 grupos hay 6 pares posibles. Si corrés 6 t-tests al α=0.05 cada uno, la probabilidad de obtener al menos un falso positivo es 1 − 0.95⁶ ≈ 26%. ANOVA testea TODO en un solo F (mantiene α=5%). Tukey HSD ajusta los pares. Nunca hagas "todos contra todos" sin corrección.

EL CÓDIGO QUE VAMOS A CORRER
ANOVA con scipy + Tukey con statsmodels
from scipy import stats
from statsmodels.stats.multicomp import pairwise_tukeyhsd

# Cada sucursal es un array de 0/1 (default sí/no), simulado con Bernoulli
f_stat, p_anova = stats.f_oneway(
    datos_lima, datos_arequipa, datos_trujillo, datos_piura,
)
print(f"F = {f_stat:.3f}, p = {p_anova:.4f}")
# → F ≈ 2.8, p ≈ 0.037

# Post-hoc Tukey HSD · p-valor ajustado por pares
tukey = pairwise_tukeyhsd(endog=df["default"],
                          groups=df["sucursal"], alpha=0.05)
print(tukey)
# → Trujillo vs Lima · p-adj < 0.05 · diferencia significativa

RECHAZAR H₀ contundente

Evidencia muy fuerte. Producto y default NO son independientes. Para saber dónde rompe la independencia, miramos los residuos estandarizados (Consumo positivos altos, Hipotecario negativos altos).

EL CÓDIGO QUE VAMOS A CORRER
Tabla de contingencia + Chi² + residuos
import numpy as np
from scipy import stats

# Solo las celdas O (sin totales). Filas: producto; columnas: al_día, default
matriz_obs = np.array([
    [1850, 105],   # Consumo
    [1480,  20],   # Hipotecario
    [1390,  60],   # Tarjeta
    [  95,   5],   # Vehicular
])

chi2_stat, p_valor, gl, esperados = stats.chi2_contingency(matriz_obs)
print(f"χ² = {chi2_stat:.2f}, gl = {gl}, p = {p_valor:.6f}")
# → χ² = 19.34, gl = 3, p < 0.001

# Residuos estandarizados · |r| > 2 indica celda que rompe independencia
residuos = (matriz_obs - esperados) / np.sqrt(esperados)
PARA LLEVAR AL DIRECTORIO
"La hipótesis de la CRO se confirma. Consumo tiene 5.4% de default vs Hipotecario apenas 1.3%. La diferencia no es atribuible al azar (p < 0.001). Acción: revisar política de aprobación de Consumo, especialmente en Trujillo y Piura (Caso 03)."
